# Studies DB — Plan 3: File-Processing Worker

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A worker process that drains the `jobs` table: converts Office documents to PDF previews with LibreOffice, extracts text for full-text search, retries with backoff, recovers stale jobs, and marks materials `ready`/`failed`.

**Architecture:** `queue.ts` owns all job-table state transitions (claim, complete, fail, requeue, finalize); `convert.ts` / `extract.ts` are pure process wrappers around `soffice` and `pdftotext`; `handlers.ts` connects them; `index.ts` is a poll loop with bounded concurrency.

**Tech Stack:** Node 22 (`child_process.execFile`), LibreOffice headless (`soffice`), poppler `pdftotext`, `@studies/db`, Vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-10-studies-db-design.md` (§6, §8)

**Depends on:** Plan 1 complete. (Independent of Plan 2; tests insert materials directly with `insertMaterial`.)

## Global Constraints

- All Plan 1 global constraints apply.
- Poll interval **3 s**; concurrency **2** (env `WORKER_CONCURRENCY`, default 2).
- Timeouts: conversion **120 s**, extraction **30 s**; on timeout the child process is killed.
- Retries (spec §6: "retry up to 3×, backoff 1 / 5 / 30 min"): max **4 attempts** (1 + 3 retries); backoff after attempt 1 → **1 min**, 2 → **5 min**, 3 → **30 min**; 4th failure → job `failed`, material `failed`.
- Stale lock: `running` jobs with `locked_at` older than **10 min** are re-queued (without incrementing attempts beyond the max).
- Extracted text truncated to **1 048 576 bytes** UTF-8 at a character boundary.
- Each `soffice` invocation uses its own profile dir (`-env:UserInstallation=file://<tmpdir>`) so concurrent conversions don't collide; tmp dir removed afterwards.
- Previews deduplicated by sha256: skip conversion if `previews/<sha>.pdf` already exists.
- Env: `DATABASE_URL`, `STORAGE_DIR`, optional `WORKER_CONCURRENCY`, `SOFFICE_BIN` (default `soffice`), `PDFTOTEXT_BIN` (default `pdftotext`).

## Review Focus

1. **Corrupt / password-protected Office or PDF file** — expected: job retries then material `failed`; file still listed and downloadable; worker keeps running. → Task 3 test `corrupt docx ends failed after 4 attempts`.
2. **Two materials with identical content processed concurrently** — expected: both end `ready` with the same `preview_path`; no corrupt half-written preview. → Task 3 test (conversion writes to tmp then `rename`).
3. **Worker killed mid-job** — expected: job re-queued after 10 min, processed once. → Task 1 test `requeueStale`.
4. **Text file in non-UTF-8 encoding (Windows-1250 from Polish Windows)** — expected: no crash; text stored with replacement chars. → Task 2 test.
5. **Very large extracted text with multibyte chars at the 1 MB boundary** — expected: valid UTF-8, ≤ 1 048 576 bytes. → Task 2 test `truncateUtf8`.

### Task 1: Job queue state machine

**Files:**
- Create: `apps/worker/package.json`, `apps/worker/tsconfig.json`, `apps/worker/vitest.config.ts`, `apps/worker/src/queue.ts`
- Test: `apps/worker/test/queue.test.ts`

**Interfaces:**
- Consumes: `Db`, tables `jobs`, `materials`, `insertMaterial`, `resetTestDb` (`@studies/db/testing`).
- Produces:
  - `Job = { id: number; materialId: number; type: JobType; attempts: number }`
  - `MAX_ATTEMPTS = 4`, `BACKOFF_MS = [60_000, 300_000, 1_800_000]`, `STALE_LOCK_MS = 600_000`
  - `claimJob(db, now?: Date): Promise<Job | null>` — transaction: `SELECT … WHERE status='queued' AND run_after <= ? ORDER BY id LIMIT 1 FOR UPDATE SKIP LOCKED`, then set `running`, `locked_at=now`, `attempts=attempts+1`.
  - `completeJob(db, job: Job): Promise<void>` — `done`, then `finalizeMaterial`.
  - `enqueueJob(db, materialId: number, type: JobType): Promise<void>`
  - `failJob(db, job: Job, err: unknown, now?: Date): Promise<'retry' | 'failed'>` — stores `last_error` (message, max 2000 chars); `attempts < MAX_ATTEMPTS` → `queued` with `run_after = now + BACKOFF_MS[attempts-1]`; else `failed` and material `status='failed'`.
  - `requeueStale(db, now?: Date): Promise<number>` — returns count re-queued.
  - `finalizeMaterial(db, materialId: number): Promise<void>` — if no jobs for material in `queued|running` and none `failed` → material `ready`.

- [ ] **Step 2:** `pnpm --filter @studies/worker test` → FAIL.
- [ ] **Step 3:** Implement with Drizzle + raw `sql` for `SKIP LOCKED`.

### Task 3: Job handlers & main loop

**Files:**
- Create: `apps/worker/src/handlers.ts`, `apps/worker/src/index.ts`
- Modify: root `package.json` (`dev:worker` script), `.env.example`
- Test: `apps/worker/test/handlers.test.ts`

**Interfaces:**
- Consumes: Task 1 queue, Task 2 converters, `previewRelPath`, `planProcessing`.
- Produces:
  - `WorkerDeps = { db: Db; storageDir: string; sofficeBin: string; pdftotextBin: string }`
  - `runJob(deps: WorkerDeps, job: Job): Promise<void>` — throws on failure (caller calls `failJob`).
    - `convert`: if `previews/<sha>.pdf` missing → `convertToPdf(original, preview)`; set `materials.preview_path`; `enqueueJob(materialId, 'extract_text')`.
    - `extract_text`: source = `preview_path` if `preview_kind='pdf'` and set, else original if PDF, else `readTextFile(original)` for `text`; store `truncateUtf8(text, 1_048_576)` in `extracted_text`.
  - `processOne(deps): Promise<boolean>` — claim → run → complete/fail; returns whether a job was processed.
  - `startWorker(deps, opts: { concurrency: number; pollMs: number; signal: AbortSignal }): Promise<void>` — runs `concurrency` loops; each loop calls `processOne` repeatedly and sleeps `pollMs` when idle; runs `requeueStale` every 60 s; resolves when `signal` aborts and in-flight jobs finish.
