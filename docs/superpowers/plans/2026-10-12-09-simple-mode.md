# Tryb prosty (simple mode) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the student-facing "Prosty" view from the Claude Design project (Start, subject, recent, search, reports, Plan zajęć, preview) under `/s/...`, with a remembered Prosty/Zaawansowany switch, Prosty as the default.

**Architecture:** A new Next route group `app/(simple)/s/` with its own layout (simple shell, no phpMyAdmin nav/console). Data comes from a new `lib/simple-queries.ts` (app pool, Drizzle) plus existing helpers (`searchAll`, `runReadonlyQuery`, `listSubjectLecturers`, plan queries, `PreviewPanel`, `PlanWeekTab`). A cookie `studiesdb.mode` decides where `/` goes; `/mode` switches and maps to the equivalent page.

**Tech Stack:** Next 16 (app router, webpack), React, Tailwind tokens in `apps/web/app/globals.css`, Drizzle/MariaDB, vitest, Playwright, `@phosphor-icons/react`.

**Spec:** `docs/superpowers/specs/2026-10-12-simple-mode-design.md`

## Global Constraints

- All UI copy Polish, exactly as the spec quotes it (e.g. "Szukaj plików i tematów", "Wybierz przedmiot, aby zobaczyć materiały z zajęć.", "Brak plików dla wybranych filtrów.", "Gotowe zestawienia", "Zobacz zapytanie SQL", "Pobierz CSV").
- Visual language: existing tokens (accent `#235a81` = `accent`/`accent-ink` tokens, zinc greys, Geist/Geist Mono), light AND dark themes, phone layout (sidebar becomes a drawer below 768px, preview panel full screen) — use the taste skills (`design-taste-frontend`, `minimalist-ui`) for UI tasks; don't invent a new visual language.
- Mode cookie: name `studiesdb.mode`, values `simple` | `advanced`, path `/`, max-age 1 year, SameSite=Lax. Missing/invalid cookie = `simple`.
- Advanced URLs and behaviour unchanged except: `/` redirects to `/s` in simple mode, and the advanced top bar shows the switch.
- No new DB views/migrations. Report SQL runs only via `runReadonlyQuery` on the RO pool.
- `/mode?next=` accepts only same-origin relative paths starting with a single `/` (reject `//…`, `/\…`, absolute URLs, control chars).
- Commands: `export PATH=$HOME/.local/bin:$PATH`; `pnpm --filter @studies/web test`, `pnpm --filter @studies/web exec tsc --noEmit`, `pnpm lint`, `pnpm --filter @studies/web e2e`.

## Review Focus

1. **Open redirect via `/mode?next=`** — `//evil.com`, `/\evil.com`, `https://evil.com`, `%2F%2Fevil` must land on the mode's home. Test in Task 1.
2. **Search input with regex / LIKE metacharacters** (`(`, `[`, `%`, `_`, `\`) — highlight must not throw and LIKE must match literally. Tests in Task 2.
3. **Subject with no files / no tags / no groups** (all 9 real subjects today have zero files) — Start cards say "brak plików", subject page shows the empty state, chip rows without options are hidden (Rodzaj shows only "Wszystko"). Test in Task 2 (queries) and Task 6 (e2e on an empty subject).
4. **Stale `?file=` / `?class=` / `?group=` / `?tag=` params** (deleted file, other subject's tag, kind without groups) — ignored, page renders. Tests in Task 2/4.
5. **Existing advanced e2e and deep links after the default flips to Prosty** — login lands on `/s`; advanced deep links still render. Task 1 (session cookie) and Task 6.
