# Glossary: interface vocabulary

The interface (website and Discord bot) is English. Content stays Polish: subject, file, lecturer and room names,
descriptions, topic titles, seed data, and the class-type tags Wykład, Laboratorium, Ćwiczenia, Projekt, Seminarium,
`Gr. N` (also `Gr3`, `Grupa 3`, `G3`). Stored keys (`kolokwium`, `egzamin`, ...), cookie names, `custom_id`s, URLs
and Discord channel names are unchanged.

Every task follows this table and adds any term it introduces. Dates display as en-GB, 24-hour, Warsaw wall clock
("Tue 20 Oct 2026, 10:00"; all-day events "Tue 20 Oct 2026, all day"; September is "Sep", never "Sept"); collation stays `'pl'`; plurals are English (`plural(n, 'file', 'files')`).
